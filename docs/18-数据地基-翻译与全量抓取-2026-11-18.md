### 翻译格式暴露的两个 bug（已修）

译名统一成「禁军：阿拉鲁斯禁军」这种**带全角冒号**的格式后，国内链路全线失效：

1. `search_queries` 只按空格切分 → 整串带着冒号丢给闲鱼，**实测 3/3 返回 0 条**；
2. `core_tokens` 也没按冒号切分 → 整串成了一个 token，`tk in title` 永不成立，
   **实测 12/12 被"相关筛除"**。

修法：两处都先把 `：:，,、/／·•` 统一当分隔符。修完实测 01-13 拿到 22 条非数字商品、全部相关，
中位 ¥270（官店 ¥499），符合第三方/翻模市场行情。

## 二、海外目录：从"逐商品搜索"改成"整站分类抓取"

### 为什么换路子

原来的 `--fetch-overseas` 是**逐商品搜索**：1745 个商品 × 约 10 秒 = 5 小时，且每次都要重新匹配。

实测发现 Element Games 的**子分类页一页就有 26–104 个商品带价格**，一个 40k 入口页就能发现
**133 个子分类**。于是改成：入口页 → 子分类页 → 一次性抽走整页商品。

### 新增

- 表 `overseas_catalog`：`url` 主键、`title`、`price`、`currency`、`category_path`、`product_id`（后处理填）、
  `match_score`、`crawled_at`。**保留所有抓到的商品，包括对不上 GW 货号的**——"没匹配上"本身就是数据。
- 脚本 `scripts/crawl_overseas_catalog.py`：6 个入口（40k / AoS / 荷西 / 涅克洛蒙达 / 血碗 / 杀戮小队）
  → 自动发现子分类 → 逐页抽「标题 + £ 价格 + 链接」→ upsert。

### 进度（后台运行中）

```
已抓 1213 个商品 / 17 个分类页
单页产出：26–104 个
```

按 6 个入口约 300+ 分类页估算，全量约 8000–15000 个 SKU，预计 30–40 分钟跑完。
