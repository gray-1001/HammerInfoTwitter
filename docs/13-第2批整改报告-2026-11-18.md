## 1. 转载降权（N-2）

### 问题复现

今天槽 2 的 NVIDIA 驱动新闻拿 57.8 分，压过真正的战锤新闻（55.6）。看它的"独立来源"：

```
nvidia.com          L2   ← 厂商自己
blogs.nvidia.com    L2   ← 还是厂商自己
tweaktown.com       L2   ← 转载媒体
```

**三家"独立来源"里两家是同一家厂商的子域**，第三家是转载。而战锤新闻只有 1 家（`belloflostsouls.net` 出现两次，同域）。

### 改法（两处）

1. **按注册域计数**：`blogs.nvidia.com` → `nvidia.com`。同一厂商的子域不再算两个独立信源。
   - 新增 `registrable_domain()`，处理 `co.uk` 这类两段后缀。
   - 回归测试抓到过一个坑：折叠子域会把 `news.google.com` 变成 `google.com`，绕过聚合器黑名单 —— 已改为先判聚合器再折叠。
2. **按来源类型加权**：`buzz` 不再直接数条数，而是加权数：

   | 层级 | 权重 |
   |---|---|
   | L0 / L1（官方、原创报道） | 1.0 |
   | L2（一般媒体、转载） | 0.6 |
   | L3（自媒体、未证实） | 0.3 |

   `buzz = min(5, 1 + 0.9 × (加权数 − 1))`

### 效果（同一批数据重算）

| 事件 | 改前 | 改后 | buzz |
|---|---|---|---|
| NVIDIA 驱动新闻 | 57.8（第 2 名） | **50.9（掉出前 10）** | 2.8 → 1.18 |
| 荷鲁斯之乱新核心任务 | 55.6 | **68.0（第 1）** | 1.0 → 1.9 |
| 暗潮修女见习者 | 66.2 | 65.8（第 2） | — |

`rubric_version` 已从 `importance@v1` 升到 `importance@v2`，doctor 里能看到。

## 2. P1-5 `--force` 不再破坏已发布内容

### 改前三处危险

1. `--force` 把 `published_day` 置 False → 渲染直接写站点根，**发送前就把读者看到的报告换掉了**；
2. 发送失败时，台账里已送达行的 `payload`/`sent_at` 被新值覆盖 —— 台账说"12:49 送达了 X"，读者实际收到的是"12:04 的 Y"；
3. 失败后 `set_stories_status(..., "scored")` 把已推送事件降级，污染去重依据。

### 改法

| 位置 | 改动 |
|---|---|
| `runner.py` | 新增 `reprint = not dry_run and force and delivered_today`；重推时先渲染到 `_dryrun`，**发送成功后才** `_publish_report()` 覆盖站点根与 `latest.html` |
| `runner.py` | 重推失败时不动站点根、不降级 story 状态 |
| `db.py` | `begin_push_batch` 的 upsert 加 `WHERE pushes.delivery_ok <> 1` —— 已送达的行是**不可变历史** |
| `db.py` | 失败/在途（0/2）的行仍允许被重试覆盖 |

### 验证（单测 + 演练）

- 失败路径：站点文件仍是 `ORIGINAL`，台账 `payload` 仍是 `ORIGINAL`；
- 成功路径：站点被替换、`stats["republished"]` 出现、台账 `payload` 仍不可变。

## 3. P1-6 三种静默失败

| 场景 | 改前 | 改后 |
|---|---|---|
| 运行锁被占用 | `{"status":"locked"}`，CLI 退出 **0**，无告警 | CLI 退出 **4**（实测），写 `alert.log` |
| 全部源采集失败 | 拿旧内容照推，`run ok`，退出 0 | 判定 `collect_dead`，**不推送**，写 alert，退出 3 |
| `push.dry_run=true` | `PreviewNotifier` 返回 True → 写 `delivery_ok=1`、`pushed_today=True`，挡住当天真推 | 只预览：**不写台账**、`push.ok=False`、退出 3 |

`PreviewNotifier` 现在带 `preview = True` 标记，runner 据此分流。

**实测**（生产库，13:55）：

```
$ run.py run --no-collect     # 今天已推过
  "push": "already_pushed"    exit=0

$ run.py run --no-collect     # 手动放一个锁文件
  "status": "locked"          exit=4
  logs/alert.log: 今日日报推送失败：运行锁被占用，本次未执行
```
