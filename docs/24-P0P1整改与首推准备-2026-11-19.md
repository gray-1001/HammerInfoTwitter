## 四、一个差点翻车的坑（已修）

清空历史时我把 `latest.html` 归档了，而 **`service_ready()` 是拿 `/latest.html` 探活的**：

```
service_ready → GET /latest.html → 404 → 判定「日报服务没起」
            → runner 记录「日报服务未就绪，已跳过推送」
            → 明天 12:00 直接不推，而且看起来像"服务问题"
```

修法：

1. 服务端新增 `/healthz`（只回答「活着」，不依赖任何内容文件）；
2. `service_ready()` 先探 `/healthz`，老版本 404 时再退回 `/latest.html`；
3. 重启日报服务让新路由生效（新 PID 131880），实测 `/healthz` 200；
4. `latest.html` 放占位页，兼顾「不 404」与「不冒充已发布」。
