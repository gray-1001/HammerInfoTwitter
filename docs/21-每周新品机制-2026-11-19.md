# 每周新品机制（2026-11-19）

> 需求：**每周抓一次新品，把抓到的信息更新到商品信息目录里**（重点是模型和小说，不含涂料）。

---

## 一、机制

### 定时

```
任务名   InfoTwitter-Price-Weekly
时间     每周一 09:00
执行     .venv\Scripts\python.exe scripts\weekly_price_update.py
日志     logs\price-weekly.log
下次     2026-11-23 09:00
```

与每日推送任务（`InfoTwitter-Daily` 12:00）**完全独立**：价格更新跑挂了不影响日更。

```powershell
# 注册 / 改时间 / 卸载
powershell -ExecutionPolicy Bypass -File scripts\install_weekly_task.ps1
powershell -ExecutionPolicy Bypass -File scripts\install_weekly_task.ps1 -At 08:30 -DayOfWeek Sunday
powershell -ExecutionPolicy Bypass -File scripts\install_weekly_task.ps1 -Uninstall
```

注：S4U 注册在这台机器上被拒（`Access is denied`），退回 Interactive 模式——
**需要保持登录**才会执行，与每日任务一致。

### 流程（`weekly_price_update.py` 串起来）

| 步骤 | 脚本 | 做什么 | 失败时 |
|---|---|---|---|
| 1 | `crawl_overseas_catalog.py` | 抓 7 个入口 + 子分类页 | **全入口失败 → 退出码 2，整轮中止**（不拿旧数据冒充新品） |
| 2 | `fill_catalog_codes.py --since-days 7` | 只给本周新出现的行补货号 | 连续失败 5 次熔断，保留进度 |
| 3 | `import_new_products.py --since-days 7` | 新品补进 `products` | 幂等，可重复跑 |
| 4 | `translate_products.py` | 给新品起中文名 | 只处理没译名的 |
| 5 | `match_catalog.py --write-points` | 匹配 + 写 `gw_uk` 价格点 | 秒级 |

### 「新品」怎么判定

`overseas_catalog.first_seen_at`：URL **第一次**出现在目录里的时间。
每次抓取只更新 `crawled_at`，`first_seen_at` 保持首次值（`ON CONFLICT` 时不覆盖）。
所以「本周新品」= `first_seen_at >= 今天-7天` 且主表还没有的商品。

### 什么进目录、什么不进

| 收 | 不收 | 理由 |
|---|---|---|
| 模型（mini） | 涂料（paint） | 用户明确不需要涂料价格 |
| 盒装（boxed） | 英文圣典（codex） | 中文版已有，且版本不同不可比 |
| 地形（terrain） | 周边卡牌（accessory） | 不是价格关注对象 |
| 小说/规则书（book） | 非战锤品类（桌游/卡牌/星战） | 与业务无关 |

品类判定顺序：**目录分区路径**（`blacklibrary`/`books`）→ 标题书籍特征 → `classify_category()` → 兜底 `mini`。
分区路径最可靠——`DARK IMPERIUM (ENGLISH)` 光看标题会被判成模型。

## 二、首次回填（今天做的）

`first_seen_at` 回填成历史 `crawled_at`，所以第一次跑时「7 天内新品」= 全部目录。
借这次机会做了一次性回填：

```
商品目录   1,782 → 2,332（+550）
匹配商品     980 → 1,530
有海外价     984 → 1,534（占 2332 的 66%）
price_points 5,411 → 5,961
```

补进来的是什么：

```
60100181794  £8.99    [book] DARK IMPERIUM (ENGLISH)
99120599010  £26.0    [mini] NECROMUNDA KAL JERICHO AND SCABS
60040599045  £32.5    [book] NECROMUNDA: HALLS OF THE ANCIENTS
99120143014  £109.0   [boxed] COMBAT PATROL: ADEPTUS CUSTODES
```

新商品全部自动翻译（550/550 成功），数据完整性检查：外键无异常、重复价格点 0、负价 0。

## 三、演练结果

用 `--skip-crawl` 跑了一遍完整链路（当时 Element 站点 502 宕机）：

```
起始：目录 5786 / 商品 2332 / 有海外价 1534
$ fill_catalog_codes.py --limit 400 --since-days 7
  连续 5 次失败，判定站点不可用，提前中止（用时 3s）   ← 熔断生效
$ import_new_products.py --since-days 7        → 待补入 0（幂等）
$ translate_products.py                        → 没有需要翻译的
$ match_catalog.py --write-points              → 匹配 1530，写 1530 个价格点
本轮结果：目录 +0 / 商品 +0 / 有价 +0
```

**关键点**：站点挂了不会写脏数据，也不会假装"本周无新品"——抓取步骤失败会直接中止整轮。

## 四、日常怎么查

```powershell
Get-ScheduledTaskInfo -TaskName 'InfoTwitter-Price-Weekly'   # 上次/下次
Get-Content logs\price-weekly.log -Tail 40                   # 最近一轮
run.py doctor                                                # 含每周任务状态
```

`doctor` 里每周任务显示 `WARN · 已注册但尚未运行过` 属正常（还没到周一）。
如果显示 `FAIL · 上次执行失败`，看日志里的退出码：2 = 站点不可用。

## 五、已知限制

1. **Element 站点近期不稳**（2026-11-19 上午开始返回 502 / 连接被关），每周任务依赖它。
   熔断能防止写脏数据，但抓不到就是抓不到。
2. **S4U 被拒**，任务需要用户已登录。
3. 抓全站 753 个分类页约 65 分钟，若站点限流会拖长；必要时用 `--crawl-pages` 只抓前 N 页。
